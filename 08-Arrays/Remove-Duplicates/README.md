# Remove Duplicates

In this task, I created an array with some duplicate values and removed the duplicate values.

## Example

Original Array:

`[10, 20, 10, 30, 40, 20, 50, 30]`

Output:

`[10, 20, 30, 40, 50]`

## Concepts Used

* Arrays
* `for` loop
* `if` condition
* `includes()`
* `push()`
* Variables

## What I Practiced

I practiced how to check if a value already exists in another array and only add it when it is not already present.

## Purpose

The purpose of this task was to practice arrays, loops, conditions, and checking duplicate values in JavaScript.

# Find Largest & Smallest Number

In this task, I created an array of numbers and found the largest and smallest number from the array.

## Example

Array:

`[12, 45, 7, 89, 23, 56, 3]`

Output:

* Largest Number: 89
* Smallest Number: 3

## Concepts Used

* Arrays
* `for` loop
* Array indexes
* `if` conditions
* Comparison operators
* Variables
* `console.log()`

## What I Practiced

I practiced how to compare array values one by one and update the largest and smallest values.

I used the first array element as the starting value and then compared the remaining values with it.

## Purpose

The main purpose of this task was to practice working with arrays, loops, and comparisons in JavaScript.

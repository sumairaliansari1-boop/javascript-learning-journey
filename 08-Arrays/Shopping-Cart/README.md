# Shopping Cart

In this task, I created a simple shopping cart using an array of product prices.

I used a loop to calculate the total price of all products in the cart.

## Example

Cart:

`[1200, 500, 2500, 800]`

Output:

`Total Cart Price: 5000`

## Concepts Used

* Arrays
* `for` loop
* Variables
* Array index
* Addition
* `console.log()`

## What I Practiced

I practiced how to go through an array using a loop and add all the values together.

## Purpose

The purpose of this task was to practice arrays and loops by making a simple shopping cart calculation.

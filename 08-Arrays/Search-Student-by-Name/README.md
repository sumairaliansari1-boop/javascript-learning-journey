# Search Student by Name

In this task, I created a list of students and searched for a specific student name in the array.

## How It Works

The program checks whether the entered student name exists in the student list.

If the student is found, it shows:

`Student found in student list`

If the student is not found, it shows:

`Student not found in student list`

## Concepts Used

* Arrays
* `includes()`
* `if / else`
* Variables
* Template literals
* `console.log()`

## What I Practiced

I practiced how to search for a value inside an array using `includes()`.

## Purpose

The main purpose of this task was to practice basic array searching in JavaScript.

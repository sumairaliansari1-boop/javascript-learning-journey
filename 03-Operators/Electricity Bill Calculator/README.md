******************  Electricity Bill Calculator  ******************************

A simple JavaScript program to calculate electricity bills based on consumed units.

## Description

This program calculates the electricity bill using different rates for different unit ranges.
## Supported Units

- 1–100 units → Rs. 10 per unit
- 101–200 units → Rs. 15 per unit
- 201–300 units → Rs. 20 per unit

## Example

For 250 units:

- First 100 units = Rs. 1000
- Next 100 units = Rs. 1500
- Remaining 50 units = Rs. 1000

**Total Bill = Rs. 3500**

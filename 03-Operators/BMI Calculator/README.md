# BMI Calculator

A beginner-friendly BMI Calculator built with JavaScript
I am applying fundamental programming concepts through small practical projects.

## Overview

The calculator takes a person's weight and height and calculates their Body Mass Index (BMI) using the standard BMI formula.


## Current Features

* Accepts weight in kilograms
* Accepts height in meters
* Calculates BMI using JavaScript arithmetic operators
* Displays the BMI value rounded to two decimal places


## JavaScript Concepts Practiced

* `const` variables
* Arithmetic operators
* Mathematical expressions
* Template literals
* `toFixed()` method




## Purpose

The goal of this project is to strengthen JavaScript fundamentals by building a practical application incrementally rather than implementing everything at once.

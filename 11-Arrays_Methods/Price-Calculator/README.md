# Price Calculator

In this task, I created a simple price calculator using an array of prices.

I used the `reduce()` method to calculate the total price.

## Example

Prices:

`[1200, 500, 2500, 800, 1500]`

Total:

`6500`

## What I Practiced

* Arrays
* `reduce()`
* Callback function
* Accumulator
* Current value

The main purpose of this task was to understand how `reduce()` works and how multiple values can be combined into one result.

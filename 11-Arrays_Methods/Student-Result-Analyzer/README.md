# Student Result Analyzer

In this task, I created a simple student result analyzer using an array of marks.

The program calculates the total marks, average marks, highest marks, and lowest marks.

## Example

Marks:

`[78, 85, 92, 67, 74, 88]`

Output:

`Total Marks: 484`
`Average Marks: 80.67`
`Highest Marks: 92`
`Lowest Marks: 67`

## Methods Used

* `reduce()`

## What I Practiced

I practiced using `reduce()` to calculate the total, highest, and lowest marks.

I also calculated the average using the total marks and the length of the array.

The purpose of this task was to get more practice with array methods and working with calculated results.

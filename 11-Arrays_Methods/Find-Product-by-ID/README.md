# Find Product by ID

In this task, I created an array of product objects and searched for a product using its ID.

## Example

I used product information such as:

* Product ID
* Product Name
* Price
* Category

The program searches for a product ID and returns the matching product.

If the product ID does not exist, it shows:

`Product Not Found`

## Method Used

* `find()`

## Concepts Used

* Arrays
* Objects
* `find()`
* Callback function
* Object properties
* `if / else`
* `console.log()`

## What I Practiced

I practiced how to use the `find()` method with an array of objects and search for a specific product using its ID.

## Purpose

The purpose of this task was to practice the `find()` array method and working with objects inside an array.

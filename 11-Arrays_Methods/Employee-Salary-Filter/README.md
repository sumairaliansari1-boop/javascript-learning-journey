# Employee Salary Filter

In this task, I created an array of employee salaries and filtered the salaries based on a minimum salary limit.

## Example

Minimum Salary:

`50000`

Salaries:

`[25000, 45000, 60000, 35000, 80000, 50000]`

Output:

`[60000, 80000, 50000]`

## Method Used

* `filter()`

## Concepts Used

* Arrays
* `filter()`
* Callback function
* Parameters
* `return`
* Comparison operators

## What I Practiced

I practiced how to use the `filter()` method to get only those salary values that meet a specific condition.

## Purpose

The purpose of this task was to practice the `filter()` method in JavaScript with a simple real-life example.

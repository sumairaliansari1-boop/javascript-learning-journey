# Username Generator

In this task, I created a simple username generator using a full name.

I used different string methods to clean the name and convert it into a username.

## Example

Input:

`  Sumair Ali Ansari  `

Output:

`sumair_ali_ansari`

## String Methods Used

* `trim()`
* `toLowerCase()`
* `replaceAll()`

## What I Practiced

I practiced how to remove extra spaces, convert a string to lowercase, and replace spaces with underscores.

## Purpose

The purpose of this task was to practice basic string methods in JavaScript by creating a simple username generator.

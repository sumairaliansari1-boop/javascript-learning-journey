# Password Validator

In this task, I created a simple password validator using JavaScript string methods.

The program checks whether a password meets the required conditions.

## Conditions

The password should:

* Have at least 8 characters
* Contain at least one number

If both conditions are met, the password is considered valid.

## Example

```text
Password: Sumair123
Output: Password is Valid
```

## Concepts Used

* Strings
* `.length`
* `includes()`
* `if / else`
* Logical operators
* `console.log()`

## What I Practiced

I practiced how to check the length of a string and search for specific characters inside a string using `includes()`.

The purpose of this task was to practice string validation using basic JavaScript conditions and string methods.

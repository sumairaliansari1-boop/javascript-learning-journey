# Employee Salary Calculator

In this task, I created a function to calculate an employee's final salary.

## Calculation

Final Salary = Basic Salary + Allowance - Deduction

## Example

* Basic Salary: 50000
* Allowance: 5000
* Deduction: 2000
* Final Salary: 53000

## Concepts Used

* Function declaration
* Multiple parameters
* Arguments
* `return`
* Arithmetic operators
* Function calling
* Variables
* `console.log()`

## What I Practiced

I practiced how to pass multiple values to a function and return the final calculated salary.

## Purpose

The main purpose of this task was to practice using functions with multiple parameters and `return` in a real-life example.

# Simple Calculator Functions

In this task, I created four functions for basic calculator operations.

## Functions

1. Addition
2. Subtraction
3. Multiplication
4. Division

## Concepts Used

* Function declaration
* Parameters
* Arguments
* `return`
* Arithmetic operators
* Function calling
* `console.log()`

## What I Practiced

I practiced how to pass multiple values to a function and return the calculated result.

I also practiced using the returned value outside the function.

## Purpose

The main purpose of this task was to practice functions with multiple parameters and understand how `return` works in JavaScript.

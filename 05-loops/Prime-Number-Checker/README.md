# Prime Number Checker

A simple JavaScript program that checks whether a given number is a Prime Number or Not a Prime Number.

## How It Works

The program uses a `for` loop to check how many numbers can divide the given number completely.

* If the number is divisible by only 1 and itself → Prime Number
* Otherwise → Not a Prime Number

## Concepts Used

* Variables
* `for` loop
* `if / else`
* Modulus Operator (`%`)
* Comparison Operator (`===`)
* Counter (`count++`)
* console.log()

## Example

```text
10 is Not a Prime Number
```

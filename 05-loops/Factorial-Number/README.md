# Factorial Number

A simple JavaScript program that calculates the factorial of a given number using a `for` loop.

## How It Works

The program starts with `1` and multiplies it by each number from the given number down to `1`.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## Concepts Used

* Variables
* `for` loop
* Multiplication (`*`)
* Multiplication Assignment (`*=`)
* Template Literals
* `console.log()`

## Example Output

```text
Factorial of 10 is 3628800
```

## Purpose

I made this project to practice **JavaScript Loops** and understand how factorial calculations work using a loop.

# Nested Loop Patterns

In this practice task, I created 10 different patterns using JavaScript nested loops.

## Patternsss

1. Square
2. Increasing Triangle
3. Decreasing Triangle
4. Number Triangle
5. Same Number Triangle
6. Reverse Number Triangle
7. Increasing Number Pattern
8. Right Aligned Triangle
9. Pyramid Pattern
10. Reverse Pyramid

## Concepts Used

* `for` loop
* Nested `for` loops
* Variables
* Increment and decrement
* String concatenation
* `console.log()`

## Purpose

I made this task to practice **nested loops** and understand how outer and inner loops work together to create different patterns.

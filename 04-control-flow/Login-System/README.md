# Login System

A simple JavaScript program that checks a username and password.

## How It Works

* Correct username and password → Login Successful
* Correct username but wrong password → Incorrect Password
* Wrong username → User Not Found

## Concepts Used

* Variables
* Comparison Operators (`===`, `!==`)
* Logical Operator (`&&`)
* `if / else if / else`
* `console.log()`

## Example Output

```text
Login Successful
```

## Purpose

This is a practice project for learning **JavaScript Control Flow**.

# Leap Year Checker

A simple JavaScript program that checks whether a given year is a Leap Year or Not a Leap Year.

## What I Used

* JavaScript
* Variables
* Modulus Operator (`%`)
* if / else if / else
* Template Literals
* console.log()

=> How It Works

The program checks the year using these conditions:

* Divisible by 400 → Leap Year
* Divisible by 100 → Not a Leap Year
* Divisible by 4 → Leap Year
* Otherwise → Not a Leap Year

## Example

```text
2024 is Leap Year
```

# Discount System

A simple JavaScript program that calculates a discount based on the shopping amount.


## Discount Rules

* 10,000 or more → 20% discount
* 5,000 or more → 10% discount
* 2,000 or more → 5% discount
* Less than 2,000 → No discount

## What I Used

* JavaScript
* Variables
* Arithmetic Operators
* Comparison Operators
* if / else if / else
* Template Literals
* console.log()

## Example

If the amount is `5000`:

```text
Original Amount: 5000
Discount: 10
Discount Amount: 500
Final Price: 4500
```

## Purpose

I made this project to practice **JavaScript Control Flow** and conditional statements.

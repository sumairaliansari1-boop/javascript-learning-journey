# Student Management System

A simple JavaScript project created to practice working with objects and object properties.

## Overview

In this task, I created a student object containing basic student information such as name, age, registration number, course, and CGPA.

The program displays the student's information and demonstrates how to update an existing property.

## Features

* Stores student information in an object
* Accesses individual properties using dot notation
* Displays student details using template literals
* Updates the student's CGPA
* Displays the updated value

## Concepts Practiced

* JavaScript Objects
* Key-Value Pairs
* Object Properties
* Dot Notation
* Updating Object Properties
* Template Literals
* `console.log()`

## Example

```text
Student Name: Sumair Ali
Age: 23
Registration Number: 24
Course: BS Information Technology
CGPA: 3.50

Updated CGPA: 3.66
```

## Purpose

The purpose of this project is to build a basic understanding of JavaScript objects and practice accessing and modifying object properties.

# Product Inventory

A simple JavaScript project created to practice working with objects and object properties.

## Overview

In this task, I created a product object containing information such as product name, price, category, stock, and product ID.

The program displays the product details, updates the price and stock, and checks whether the product is currently in stock.

## Features

* Stores product information in an object
* Accesses individual properties using dot notation
* Updates product price and stock
* Checks product availability based on stock
* Displays the updated product information

## Product Information

* Product Name
* Price
* Category
* Stock
* Product ID

## Concepts Practiced

* JavaScript Objects
* Key-Value Pairs
* Object Properties
* Dot Notation
* Updating Object Properties
* `if / else`
* Comparison Operators
* Template Literals
* `console.log()`

## Example

```text
Product Name: Wireless_Headphones
Price: 8500
Category: Electronics
Stock: 10
Product ID: 101

Updated Price: 8000
Updated Stock: 8

Product is In Stock
```

## Purpose

The purpose of this project is to practice creating, accessing, updating, and working with object properties in JavaScript using a practical product inventory example.

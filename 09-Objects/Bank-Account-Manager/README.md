# Bank Account Manager

In this task, I created a simple bank account object with some basic account information.

I also practiced adding money to the account and withdrawing money from the balance.

## Information Used

* Account Holder
* Account Number
* Account Type
* Balance
* Status

## What I Did

I created an account object and accessed its properties using dot notation.

Then I added a deposit to the balance and updated the account balance.

After that, I added a withdrawal check. If the balance was enough, the amount was deducted. Otherwise, it showed insufficient balance.

## Concepts Used

* Objects
* Object Properties
* Dot Notation
* Updating Object Properties
* `if / else`
* Comparison Operators
* Arithmetic Operators
* Template Literals
* `console.log()`

## Purpose

I made this task to practice JavaScript objects with a simple real-life example and understand how object values can be updated.
